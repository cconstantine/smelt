# Child agents

Part of the [Current state](index.md). What a conversation's model can hand off to agents of its own (SME-236, the first ticket of "Personas and sub-agents"; the design is [docs/design/personas/](<https://github.com/cconstantine/smelt/blob/main/docs/design/personas/index.md>), the mechanics [docs/api/agents.md](<https://github.com/cconstantine/smelt/blob/main/docs/api/agents.md>)).

* **Starting one.** In a conversation of the user's own (not in an agent: agents are one level deep until SME-245), the model calls `start_agent` with a brief. The agent is a new conversation, listed in the sidebar like any other and titled by its brief, with its own sandbox; the brief is its first message and the call returns its id at once, so the parent carries on.
* **On a repo, at a ref, as a persona.** With `repo` (one of the parent's checkouts), the agent gets its own clone, at `ref` or, without one, at the exact commit the parent's checkout is on, which must be pushed and clean (otherwise the call says what to do). The remote must be trusted, and the agent's top-level AGENTS.md is loaded for it. With `persona`, the agent runs under that persona file (`.agents/personas/<name>.md`) as it is at the agent's ref: its instructions go in the agent's system prompt under Persona, links made absolute, and its `smelt.model` picks the agent's model when a provider has it. Editing the file afterwards changes nothing for a running agent.
* **Hearing back.** The agent ends its work with `finish(report)`; the report arrives in the parent's transcript as "Report from agent #12 (smelt:developer):" and wakes it. A busy parent takes it at its next step; several at once arrive together. The parent is also told when an agent's turn ends without a report (with the start of its last reply), when its start fails (with why), when the user stops it, and when the user deletes it. Reports wait in the database, so a restart doesn't lose them.
* **Talking at any time** (SME-238). A parent and its agent write to each other with `message_agent`: the message arrives as "Message from agent #12 (smelt:developer):" or "Message from your parent:", waking an idle conversation or reaching a busy one at its next step. An agent can `ask_parent` a question and wait: the parent's next message to it is the answer. Siblings don't write to each other; they go through the parent.
* **Keeping track.** `list_agents` shows the parent's own agents with their status: starting, running, waiting for the user, waiting for its parent, idle, finished, stopped or failed. `stop_agent` stops one and everything under it, leaving its sandbox as it is.
* **The user's part.** The user can open an agent and watch or write to it like any conversation; writing to a finished or stopped agent wakes it again, and their Stop on it tells its parent. Deleting a conversation deletes its agents too, and the Delete button says how many ("Delete + 2 agents?").
* **Restarts.** A conversation the user stopped stays paused across a restart, for every conversation, not only agents. An agent whose turn a restart cut off is told "smelt restarted during your turn; carry on" and carries on.
* **Not yet:** volumes shared with an agent (SME-239), per-persona tool rules and credentials (SME-241, SME-242), limits on agents at once and nesting (SME-245), agents shown under their parent in the sidebar (SME-246), and messages, reports and notices styled apart from the user's own in the transcript (SME-280).
