## Visibility: one mechanical rule, zero scope changes

`pub(super)` inside `crate::sandbox::agent` means *visible in `crate::sandbox`* — exactly `pub(in crate::sandbox)`. In an `agent/` **child** module the same spelling would mean only `crate::sandbox::agent`, so **every `pub(super)` inside a moved line becomes `pub(in crate::sandbox)` — same scope, by definition** — and nothing else on that line changes. Items staying in `mod.rs` keep `pub(super)` untouched. `agent/registry.rs` already spells this exact scope `pub(in crate::sandbox)` on every item — the module's own in-file precedent for the choice. No narrowing, no widening: the split is provably scope-preserving, which is why no consumer anywhere changes and each bump is a known, script-checkable exception.

## Boundary calls (from the plan, for review)

## Proof (move-only route, `docs/process/rules-commits.md`)

Two scripts, saved to `<scratchpad>/sme-463/` and pasted into the PR description (SME-448's shape). `split463.py` **writes all three files** from `git show $BASE:src/sandbox/agent.rs` — nothing hand-edited — and `proof463.py --check` re-derives everything from `$BASE` independently and asserts. The only permitted textual exception anywhere is the `pub(super)` → `pub(in crate::sandbox)` rewrite (27 sites, listed above) plus the known insertions; the proof asserts the rewrite is exactly a replace-all on moved lines by un-rewriting and comparing bytes (`$BASE` has zero `pub(in ` occurrences — checked), so the join is byte-exact against the base.

```python
#!/usr/bin/env python3
"""SME-463: split src/sandbox/agent.rs into agent/{mod,dialer,connection}.rs.

Pure move; run from the branch after
`git mv src/sandbox/agent.rs src/sandbox/agent/mod.rs`, with BASE the branch
base (21aaf114). Writes all three files byte-exactly from git show $BASE.
"""
import pathlib, subprocess

REPO = pathlib.Path("/workspace/smelt"); BASE = "21aaf114"
orig = subprocess.run(["git", "show", f"{BASE}:src/sandbox/agent.rs"],
                      cwd=REPO, capture_output=True, check=True).stdout
lines = orig.splitlines(keepends=True)
assert len(lines) == 853 and len(orig) == 38822
def rng(a, b): return b"".join(lines[a - 1:b])
for i in (124, 273, 585): assert lines[i - 1] == b"\n"
assert lines[850] == b"mod registry;\n"
assert lines[852] == b"pub use registry::*;\n"
assert orig.count(b"pub(in ") == 0
PS, NEW = b"pub(super)", b"pub(in crate::sandbox)"
H1 = b"//! Reaching a pod's agent: the dialer traits, the cluster dialer, and image names.\n\nuse super::*;\n\n"
H2 = b"//! One pod's agent connection: `TerminalConnection` and its request machinery.\n\nuse super::*;\n\n"
INS = b"mod connection;\n\npub use connection::*;\n\nmod dialer;\n\npub use dialer::*;\n\n"
S1, S2, S3 = rng(6, 123), rng(125, 272), rng(586, 608)
assert (S1.count(PS), S2.count(PS), S3.count(PS)) == (11, 16, 0)
d = REPO / "src/sandbox/agent"; assert d.is_dir() and (d / "registry.rs").is_file()
assert (d / "mod.rs").is_file() and not (d / "dialer.rs").exists()
(d / "mod.rs").write_bytes(rng(1, 5) + rng(274, 584) + rng(609, 850) + INS + rng(851, 853))
(d / "dialer.rs").write_bytes(H1 + S1.replace(PS, NEW))
(d / "connection.rs").write_bytes(H2 + S2.replace(PS, NEW) + b"\n" + S3)
print("split written")
```

```python
#!/usr/bin/env python3
"""SME-463 move-only proof. proof463.py --check, run at the branch.

Checks: (1) each new file, minus its known inserted lines, is its slice of
$BASE byte-for-byte, with the ONLY diff on any line the listed
pub(super)->pub(in crate::sandbox) rewrite (un-rewrite == base bytes; $BASE
contains no pub(in )); (2) the three slices + insertions reassemble $BASE
exactly (every base line verbatim, in order, in exactly one place); (3) every
fn/struct/enum/const/trait/type name, duplicates kept, appears in exactly one
new file at the same count as base; (4) every file of the module <= 30000 B
and the rewrite counts are exactly 11/16/0 and 0/0/0 for mod.rs.
"""
import re, subprocess, sys, pathlib
BASE = "21aaf114"; R = pathlib.Path("/workspace/smelt")
orig = subprocess.run(["git", "show", f"{BASE}:src/sandbox/agent.rs"],
                      cwd=R, capture_output=True, check=True).stdout
lines = orig.splitlines(keepends=True)
def rng(a, b): return b"".join(lines[a - 1:b])
PS, NEW = b"pub(super)", b"pub(in crate::sandbox)"
H1 = b"//! Reaching a pod's agent: the dialer traits, the cluster dialer, and image names.\n\nuse super::*;\n\n"
H2 = b"//! One pod's agent connection: `TerminalConnection` and its request machinery.\n\nuse super::*;\n\n"
INS = b"mod connection;\n\npub use connection::*;\n\nmod dialer;\n\npub use dialer::*;\n\n"
d = R / "src/sandbox/agent"
mod = (d / "mod.rs").read_bytes(); dia = (d / "dialer.rs").read_bytes()
con = (d / "connection.rs").read_bytes()
# (1) per-file slice proofs (un-rewritten bytes == base slice)
assert dia.replace(NEW, PS) == H1 + rng(6, 123), "dialer.rs"
assert con.replace(NEW, PS) == H2 + rng(125, 272) + b"\n" + rng(586, 608), "connection.rs"
assert mod == rng(1, 5) + rng(274, 584) + rng(609, 850) + INS + rng(851, 853), "mod.rs"
# (2) reassembly: interleaved cat of the three un-rewritten pieces is the base
rest = mod[149:].replace(INS, b"")  # mod.rs minus head lines 1-5, minus insertions
rebuilt = (rng(1, 5) + dia.replace(NEW, PS)[len(H1):] + b"\n"
           + con.replace(NEW, PS)[len(H2):len(H2) + len(rng(125, 272))] + b"\n"
           + rest[:len(rng(274, 584))] + b"\n"
           + con.replace(NEW, PS)[len(H2) + len(rng(125, 272)) + 1:]
           + rest[len(rng(274, 584)):])
assert rebuilt == orig, "JOIN"
# (3) item-name multiset: identical base vs union, each name in one file
PAT = rb"(?m)^\s*(?:pub(?:\([^)]*\))? )?(?:pub\(in [a-z: ]+\) )?(?:async )?(?:fn|struct|enum|const|trait|type) ([A-Za-z0-9_]+)"
items = lambda b: sorted(m.group(1) for m in re.finditer(PAT, b))
assert items(orig) == sorted(items(mod) + items(dia) + items(con)), "ITEMS"
for x, y in ((mod, dia), (mod, con), (dia, con)):
    assert not set(items(x)) & set(items(y)), "NAME IN TWO FILES"
# (4) sizes and rewrite counts
for f in list(d.iterdir()):
    assert f.read_bytes().__len__() <= 30000, f
assert dia.count(NEW) == 11 and con.count(NEW) == 16 and mod.count(NEW) == 0
assert mod.count(PS) == 15 and dia.count(PS) == 0 and con.count(PS) == 0
print("ALL PROOFS GREEN")
```

## Trade-offs to flag

- `mod.rs` stays the largest piece (25.7 KB) by design — SME-448's precedent, and the reconnect↔connect recursion would need two-way visibility bumps to split further. If the file grows again, the next natural cut is `connect`/`handle_agent_message` with `ConnectError` shared, which is a judgement split, not this move-only one.
- 27 visibility sites change **spelling** (`pub(super)` → `pub(in crate::sandbox)`) without changing scope — the ticket's "minimize visibility changes" resolved as zero scope changes at the cost of a mechanical rewrite, because in a child module the old spelling would mean a narrower scope. The script proves the rewrite is exactly `replace-all` on the moved lines and nowhere else.
- The misplaced doc (base 586–592) stays misplaced and lands in `connection.rs` describing `client_message_action`. Fixing it is a follow-up doc ticket at most; a move-only PR must not.
- `ACK_TIMEOUT`'s doc and name outlive the split in `dialer.rs` while its main user (`request`) is in `connection.rs` — kept in S1 because it sits at the head of the dialer block (moving it with S2 would break the contiguity of S1 for a doc-comment gain).
