# Markdown in chat

## What

A placeholder: the user plans to scope this as its own project. The model's replies render as formatted text in the chat, with headings, lists, emphasis, tables and code blocks, instead of showing the raw markdown characters.

## Why

Models naturally write markdown, and it reads better rendered. Today replies show as plain text, so the system prompt asks the model to avoid markdown. Once rendering exists, that instruction can be dropped.
